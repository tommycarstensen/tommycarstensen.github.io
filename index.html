Software

coxstream

Python · R · Cython · survival analysis

Exact out-of-core Cox proportional hazards regression. Each Newton–Raphson step becomes a sum over parquet row groups, so peak memory is flat in the number of rows while the estimates stay exact — coefficients and standard errors match survival::coxph and lifelines to numerical precision. Carries the Efron tie correction across chunk boundaries.

pip install coxstream CRAN R source

renew-glm

Python · NumPy · SciPy · generalized linear models

Streaming GLMs with bounded memory — a Python implementation of Luo & Song (2020)'s renewable estimation. One pass per iteration accumulates the sufficient statistics, so memory scales with the number of covariates rather than the number of rows. Gaussian, binomial and Poisson; agrees with statsmodels to machine precision.

pip install renew-glm

PlotPick

Python · Claude Vision · Streamlit · PyMuPDF

Recovers the numbers behind published figures. Upload images, PDFs or ZIPs and it reads boxplots, bar charts and line plots back into structured tables. Benchmarked against ChartX and PlotQA with Claude, GPT, Gemini and DePlot baselines.

Upstream

Fixes and reports accepted into the tools this work depends on.

  • polars #27860 Float >= filters could never skip parquet row groups, because Parquet's min/max statistics exclude NaN while polars orders NaN as the largest value. Root-caused with the maintainers and gated on nan_count; accepted.
  • samtools/bcftools Six merged pull requests — error messages that name the accepted types and options, and documentation corrections for the two-VCF-input statistics.
